01 / The problem

Project overview

Customer retention matters to online businesses. Our project uses recorded customer and order attributes to describe behavior and test whether returning-customer status can be predicted from available features.

Problem statement. Analyze e-commerce customer behavior to identify useful patterns across demographics, purchases, browsing activity, payment methods, and delivery experience, then compare classification models for predicting whether a record belongs to a returning customer.
01 — EXPLORE

Understand the data

Summarize numerical and categorical variables, inspect data quality, and visualize customer and order patterns.

02 — ENGINEER

Create useful features

Extract year, month, and weekday from dates, and calculate discount percentage from order price, quantity, and discount.

03 — PREDICT

Compare classifiers

Train multiple models, select using validation performance, and assess final performance on a held-out test set.

Returning vs. non-returning

2,990 records are labelled returning (59.8%) and 2,010 non-returning (40.2%). The classes are not evenly balanced, so accuracy should be interpreted alongside precision, recall, and F1-score.

▦
Category counts are close

Sports has 667 records; the other listed product categories have counts in a relatively similar range. Counts alone do not indicate which category has the highest return rate.
