# Team 10 — MDS GitHub Pages website

## Before publishing
1. Open `index.html` and replace the Team 10 member placeholder with your actual names and roll numbers.
2. Run your final notebook/source code and update the model-results section with the actual selected model and metrics. Do not guess these values.
3. Preview `index.html` in a browser.

## Publish with GitHub Pages
1. Sign in at https://github.com/
2. Click **New repository**.
3. Name it `mds-midterm-project` (or another simple name).
4. Set visibility to **Public** and create the repository.
5. Upload `index.html` (and this README if you want) to the repository root.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Choose branch **main** and folder **/(root)**, then click **Save**.
9. Wait a few minutes and refresh the Pages section. Open the published URL shown there.
10. Test the website in an incognito/private window. Submit that `https://YOUR-USERNAME.github.io/REPOSITORY-NAME/` URL in the Google Form.
11. Keep both repository and Pages site public for at least one year.

## Notes
- Charts use Chart.js from a CDN, so the browser needs internet access to load the chart library.
- The website does not include your raw CSV or Python source code; it presents a summary of the analysis.
- Verify every result against the final project output before submitting.
