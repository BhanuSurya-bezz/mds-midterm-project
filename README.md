# ReturnLab — Team 10 MDS Project Website

## Update before submission
- Replace the stylized initials in the Team section with actual photographs if your instructor requires photos.
- Confirm each member bio accurately reflects their real role/contribution.
- Replace the model-results warning with the actual best model and test metrics from your final Python run.
- Check all chart counts against your final dataset and analysis.

## Update an existing GitHub Pages site
1. Download and extract this ZIP.
2. Open your existing repository: `mds-midterm-project`.
3. Choose **Add file → Upload files**.
4. Upload the new `index.html` from this folder into the repository root.
5. Commit changes. GitHub Pages will redeploy automatically.
6. Open your same live URL in a private/incognito window to verify.

## Important
This is a single-page website with three clearly visible navigation tabs: Project, Results, and Team. It is designed to work on desktop and mobile. Charts load Chart.js from a CDN, and fonts load from Google Fonts, so internet access is required for those visual elements.
